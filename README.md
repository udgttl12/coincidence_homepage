# 코인시던스 회사 홈페이지

코인시던스 회사 소개 HTML을 GitHub Pages로 게시하는 저장소입니다.

- 홈페이지: https://udgttl12.github.io/coincidence_homepage/
- 게시 파일: `index.html`
- 게시 소스: `main` 브랜치의 루트(`/`)
- `.nojekyll`: Jekyll 처리 없이 정적 파일을 그대로 게시합니다.

## 수정 및 게시

`index.html`을 수정하여 `main` 브랜치에 커밋하고 푸시하면 GitHub Pages가 자동으로 배포합니다.

최초 게시 파일은 로컬의 `코인시던스 회사 홈페이지.html`과 내용이 동일합니다. 원본 파일은 로컬에 보관하며 중복 업로드하지 않습니다.
