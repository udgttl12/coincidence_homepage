3. 정식판과 AI판의 구분

현재 정식판은 AI 풀이 기능과 외부 AI 호출을 제공하지 않습니다. 사주 계산, 기록 관리와 비교는 기기 안에서 처리하며, 이름·생년월일시·성별·계산 결과를 외부 AI 서버에 보내지 않습니다.

AI 풀이가 포함된 별도 앱은 ‘팔자격파 AI’이며 패키지명은 kr.ai.coincidence.paljagyeokpa.ai입니다. 이 정식판의 기능과 혼동하지 않도록 구분합니다. AI판의 사용과 전송에는 해당 앱에 제공되는 별도 안내를 확인해 주세요.

과거 AI 기능이 있던 테스트 버전을 이용한 경우

이전에 배포된 AI 지원 테스트 버전에서 전문가 풀이를 요청했다면 이름 또는 별칭, 생년월일시, 성별, 계산 결과와 요청문이 HTTPS로 Grok API(api.x.ai)에 전송되었을 수 있습니다. 현재 정식판으로 업데이트하면 새로운 AI 요청은 수행하지 않습니다.

수신자는 Grok API 제공사 SpaceX Super Intelligence LLC(xAI)이며 미국 소재 법인입니다. 글로벌 API의 실제 처리 지역은 제공사의 라우팅에 따라 달라질 수 있습니다. 공개 API 정책상 요청·응답은 보안·오남용 조사 목적으로 기본 30일 보관 후 삭제되며 법률상 의무·보안 조사·계약 또는 설정에 따른 예외가 있을 수 있습니다. 제공사는 명시적 허락 없이 API 입력·출력을 학습에 사용하지 않는다고 안내합니다.

기기의 기록 삭제는 과거에 전송된 정보의 즉시 삭제를 뜻하지 않습니다. 과거 전송에 관한 문의·삭제 요청은 코인시던스 이메일 또는 제공사 support@x.ai로 접수할 수 있습니다.

제공사 기준: API 기업용 약관 · 보관·학습 정책 · 처리 지역 안내

5. 보유 기간과 파기

  • 과거 테스트 버전의 AI 전송 정보: 해당 버전에서 이미 전송된 정보에는 제3항의 제공사 보관 기준이 적용됩니다. 정식판은 새로운 외부 AI 전송을 수행하지 않습니다.
  • 문의 정보: 문의·권리행사 처리와 후속 확인이 끝나 보관 필요가 없어지면 지체 없이 삭제합니다. 법령상 보존 의무가 있으면 해당 범위·기간에 한해 분리 보관합니다.

코인시던스가 직접 보유하는 전자파일은 복구하기 어려운 방식으로 삭제하고, 출력물이 있다면 분쇄 등의 방법으로 파기합니다. 사용자가 따로 보관하거나 다른 대상에 전달한 파일은 해당 보관 위치에서 별도로 삭제해야 합니다.

6. 공유·백업과 기기 이전

결과 이미지와 백업 파일 공유는 사용자가 선택한 앱·수신자에게 정보를 전달합니다. 백업 JSON에는 이름, 생년월일시, 사주 기록, 그룹과 저장된 풀이 등이 포함될 수 있으며 평문으로 내보냅니다. API 키와 앱 설정은 사주 백업 파일에 포함하지 않습니다.

Android 백업·기기 이전이 켜져 있으면 운영체제와 기기 설정에 따라 앱 데이터가 백업되거나 이전될 수 있습니다. 이는 앱의 수동 JSON 백업과 별개입니다. 백업 범위와 삭제는 Android·Google 백업 설정 및 사용 중인 저장 서비스에서 관리해 주세요.

코인시던스는 정식판의 사주 기록을 운영 서버로 자동 수집하지 않습니다. 사용자가 선택한 공유·백업 또는 관계 법령에 따른 경우를 제외하고 사주 기록을 다른 기관에 임의로 제공하거나 판매하지 않습니다.
