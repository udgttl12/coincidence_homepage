3. 외부 AI 처리와 국외 전송

전문가 풀이 기능은 기기의 계산 결과를 외부 AI에 전달하여 해석을 작성하는 기능입니다. 사용자가 이 기능을 요청할 때 다음 정보가 전송됩니다.

서비스·수신자
Grok API (xAI) · SpaceX Super Intelligence LLC
전송 항목
이름 또는 별칭, 생년월일시, 성별, 사주 계산 결과와 이를 설명하는 풀이 요청문
목적
요청한 사주 해석 생성·반환 및 제공사의 보안·오남용 방지
시점·방법
전문가 풀이 요청 시 HTTPS로 api.x.ai에 전송
처리 지역
제공사는 미국 소재 법인입니다. 현재 앱의 글로벌 API는 처리 지역을 한 국가로 고정하지 않으며 제공사의 지역 간 라우팅에 따라 처리 위치가 달라질 수 있습니다.
보관 기준
제공사의 공개 API 정책상 일반 요청·응답은 보안·오남용 조사 목적으로 기본 30일 보관 후 삭제됩니다. 법률상 의무, 보안 조사 또는 별도 계약·설정에 따른 예외가 적용될 수 있습니다. 외부 서비스의 즉시 삭제나 무보관을 보장하지 않습니다.
학습 이용
제공사는 별도 명시적 허락 없이 API 입력·출력을 모델 학습에 사용하지 않는다고 안내합니다.
전송 거부 방법
전문가 풀이를 요청하지 않고 기기 내 기본 만세력과 기록 기능을 이용할 수 있습니다. 관련 문의·삭제 요청은 코인시던스 이메일로 접수할 수 있습니다.

외부 서버는 요청 처리 과정에서 접속 IP와 요청 시각 등 통신 정보를 처리할 수 있습니다. 앱에 저장한 풀이 사본은 기기에 보관되며, 기기에서 삭제해도 외부 서비스에 이미 전달된 정보가 즉시 삭제되는 것은 아닙니다.

제공사 연락처: support@x.ai · legal@x.ai

  • 글꼴: 필요한 글꼴이 기기에 없으면 Google Fonts에서 내려받을 수 있습니다. 접속 IP와 글꼴 요청 등 통신 정보가 전달될 수 있으나 앱은 글꼴 요청에 사주 입력 정보를 포함하지 않습니다. Google Fonts 안내
  • 정책 페이지 호스팅: 이 페이지는 GitHub Pages에서 제공합니다. GitHub는 방문 시 접속 IP와 요청 정보 등을 처리할 수 있으며 GitHub 개인정보처리방침이 적용됩니다. 이 페이지에는 별도의 방문 분석 스크립트나 입력 폼을 두지 않습니다.
  • 이메일 문의: 메일 발신 주소와 내용은 Gmail 등 이메일 서비스에서 처리됩니다. 주민등록번호, API 키와 인증 토큰 등 민감한 정보는 첨부하지 마세요.

  • 설정·인증 정보: 해당 설정·토큰 또는 앱 데이터를 삭제할 때까지 기기에 보관됩니다.
  • 외부 AI 전송 정보: 제3항의 제공사 보관 기준이 적용됩니다. 기기 내 삭제와 외부 서비스 측 삭제는 구분하여 처리합니다.

코인시던스가 직접 보유하는 전자파일은 복구하기 어려운 방식으로 삭제하고, 출력물이 있다면 분쇄 등의 방법으로 파기합니다. 사용자가 따로 보관하거나 다른 대상에 전달한 파일은 해당 보관 위치에서 별도로 삭제해야 합니다.

6. 공유·백업과 기기 이전

결과 이미지와 백업 파일 공유는 사용자가 선택한 앱·수신자에게 정보를 전달합니다. 백업 JSON에는 이름, 생년월일시, 사주 기록, 그룹과 저장된 풀이 등이 포함될 수 있으며 평문으로 내보냅니다. API 키와 앱 설정은 사주 백업 파일에 포함하지 않습니다.

Android 백업·기기 이전이 켜져 있으면 운영체제와 기기 설정에 따라 앱 데이터가 백업되거나 이전될 수 있습니다. 이는 앱의 수동 JSON 백업과 별개입니다. 백업 범위와 삭제는 Android·Google 백업 설정 및 사용 중인 저장 서비스에서 관리해 주세요.

코인시던스는 사용자가 선택한 공유, 요청한 외부 서비스 처리 또는 관계 법령에 따른 경우를 제외하고 사주 기록을 다른 기관에 임의로 제공하거나 판매하지 않습니다.
